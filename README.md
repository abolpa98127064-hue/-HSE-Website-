# HSE Website — مهندس علی نعمتی نیا

نسخه قابل آپلود در GitHub از آخرین فایل‌های موجود پروژه HSE.

## فایل‌ها
- `index.html` — صفحه اصلی
- `admin.html` — پنل مدیریت و ویرایش محتوای نسخه استاتیک

## اجرا
برای مشاهده سریع، `index.html` را باز کنید.

## GitHub
تمام فایل‌های این پوشه را در Repository خود (`hse-website`) آپلود کنید.

## نکته مهم
این بسته بر اساس آخرین فایل‌های پروژه موجود در فضای فایل فعلی ساخته شده است. نسخه بک‌اند Node/Express/SQLite که در مراحل قبلی پروژه درباره آن صحبت شده بود، در فضای فایل فعلی قابل بازیابی مستقیم نبود؛ بنابراین این ZIP را به‌عنوان «بسته GitHub آماده از آخرین نسخه موجود» تحویل می‌دهم و ادعای وجود بک‌اند کامل در آن نمی‌کنم.
